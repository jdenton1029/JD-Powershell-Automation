# PowerShell Automation Portfolio

A collection of PowerShell projects focused on practical IT administration, networking, security, Active Directory, and automation.

This repository is intended to demonstrate hands-on PowerShell scripting skills through small, functional projects that reflect real-world IT support and system administration tasks.

## Projects

### Networking

#### Test-IPConnectivity

A PowerShell networking utility that:

* Validates user-supplied IP addresses
* Tests connectivity using ICMP
* Calculates average response time
* Displays formatted results
* Logs each test with a timestamp
* Handles invalid input and connectivity failures
* Uses reusable functions and basic error handling

Project location:

`Networking/Test-IPConnectivity`
